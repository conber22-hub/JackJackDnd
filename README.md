# Dread Delve

A 3D multi-floor dungeon simulator for the Dread Zone beneath Saint Andral's — a Flood-style parasite campaign in Barovia (Curse of Strahd: Flood Edition, sessions 0–10 included, a Barovian overworld with procedural roads, a player character creator, and players rolling their own attacks and spells from their phones).

**Play online:** the Vercel site (it republishes on every push). **Play offline:** double-click `dread-delve.html` (Chrome or Edge). **Develop:** `npm install`, `npm run dev`. **Bake:** `npm run build`. **Test:** `npm test`.

Everything else — features, phases, code map, how to add monsters — is in [DREAD-DELVE-ROADMAP.md](DREAD-DELVE-ROADMAP.md).
