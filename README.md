# Dread Delve

A 3D multi-floor dungeon simulator for the Dread Zone beneath Saint Andral's — a Flood-style parasite campaign in Barovia. Built in honor of Chance.

**Play:** double-click `dread-delve.html` (Chrome or Edge). **Develop:** `npm install`, `npm run dev`. **Bake:** `npm run build`. **Test:** `npm test`.

Everything else — features, phases, code map, how to add monsters — is in [DREAD-DELVE-ROADMAP.md](DREAD-DELVE-ROADMAP.md).
