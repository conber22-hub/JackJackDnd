# BAROVIA VI · THE DEAD VILLAGES

**36 original low-poly 3D models** across 12 Barovian building archetypes and three visual states: **inhabited → abandoned → Hunger Moss-infested**.

They are scenery skins for the solid buildings already generated by JackJackDnd's `src/engine/settlement.js`. This pack **does not** change walkability, active doors, the authoritative campaign state, town boundaries, game saves, or networking.

## What's inside

- `assets/`: 36 self-contained `.glb` files with original geometry and embedded PBR colors.
- `js/barovia-dead-villages-data.js`: 12 archetypes, 3 stages, original narrative hints and model names.
- `js/barovia-dead-villages.js`: deterministic, pure seeded state planner and validation.
- `js/barovia-dead-villages-loader.js`: opt-in Three.js loader and replacement renderer adapter.
- `tests/dead-villages.test.js`: compatibility, determinism, no gameplay mutations, GLB validity, draw-call budgets, state and privacy checks.
- `previews/`: three-state contact sheets, rendered directly from GLB triangle geometry.
- `source/`: reproducible original 3D-model build and preview scripts (Python, trimesh, numpy, Pillow).
- `showroom.html`: interactive model browser (CDN Three.js, requires internet).
- `DM_SCENE_CARDS.md`: 12 original reveals and return visit cues.
- `WORK_HANDOFF.md`: exact integration notes for Claude/Work.

## Visual language

Decay is **not merely a tint**. Inhabited buildings have warm window light and complete doors. Abandoned buildings have missing door planks, blackened shingles, and boards nailed across windows. Infested buildings have hooked fungal ridges, vein-webbed doorframes, pallid cysts and no welcoming hearth light.

All three models in a set stay within the **same X/Z plot** and keep their front entrance in the **same place**. A different model does not make a different collision map. The generator's scale is 1 world unit per five-foot square, with +Y up and the entrance facing local +Z.
